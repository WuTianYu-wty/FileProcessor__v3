# Phase 2 功能测试指南

## 🧪 测试环境准备

### 1. 环境要求
```bash
✅ Node.js 16.x+
```

## 📋 测试清单

### ✅ 功能 1：PDF 拆分

#### 测试场景 1.1：按页码范围拆分

**步骤**：
1. 准备一个至少 20 页的 PDF 文件
2. 上传到系统（文件上传页面）
3. 进入「PDF 工具」→「PDF 拆分」
4. 选择刚上传的 PDF
5. 查看显示的 PDF 信息（页数）
6. 保持「按页码范围」模式
7. 设置第一个范围：1 - 10
8. 点击「添加范围」
9. 设置第二个范围：11 - 20
10. 点击「开始拆分」
11. 等待处理完成

**预期结果**：
- ✅ 显示成功消息
- ✅ 生成 2 个 PDF 文件
- ✅ 文件列表中出现新文件
- ✅ 文件名包含页码范围

**错误处理测试**：
- ⚠️ 页码范围超出总页数 → 应提示错误
- ⚠️ 起始页 > 结束页 → 应提示错误

---

#### 测试场景 1.2：按书签拆分

**步骤**：
1. 准备包含书签的 PDF 文件
2. 上传到系统
3. 进入「PDF 工具」→「PDF 拆分」
4. 选择该 PDF
5. 查看 PDF 信息（应显示包含书签）
6. 切换到「按书签目录」模式
7. 点击「开始拆分」
8. 等待处理完成

**预期结果**：
- ✅ 按书签章节拆分
- ✅ 文件名包含章节标题
- ✅ 每个文件包含对应章节内容

**边界测试**：
- ⚠️ 选择无书签的 PDF → 应禁用拆分按钮并提示

## 🔧 故障排查

### 问题 1：OCR 处理失败

**检查**：
1. Python 环境是否正确
2. PaddleOCR 模型是否已下载
3. 查看后端日志：`backend/logs/`
4. 检查 Python 脚本输出

**解决**：
```bash
# 测试 Python 脚本
cd python-scripts
python ocr_processor.py test.pdf output.json
```

---

### 问题 2：PDF 处理失败

**检查**：
1. PyMuPDF 是否安装
2. PDF 文件是否加密
3. 文件路径是否正确

**解决**：
```bash
# 测试 PDF 脚本
cd python-scripts
python pdf_split.py input.pdf output/ pages 1-10
python pdf_merge.py output.pdf input1.pdf input2.pdf
```

---

### 问题 3：预览不显示

**检查**：
1. 浏览器控制台错误
2. 后端 API 是否正常
3. 文件是否存在

**解决**：
```bash
# 测试预览 API
curl http://localhost:3000/api/preview/1
```
