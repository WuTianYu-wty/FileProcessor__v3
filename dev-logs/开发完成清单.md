## 🛠️ 技术实现

### 后端系统

#### 文件结构
```
backend/
├── server.js              # Express 服务器
├── database/
│   └── db.js             # SQLite 数据库操作
├── routes/
│   ├── fileRoutes.js     # 文件管理 API
│   ├── logRoutes.js      # 日志 API
│   └── exportRoutes.js   # 导出 API ⭐ 新增
└── utils/
    └── logger.js         # Winston 日志配置
```

#### 数据库表
```sql
-- files 表（已包含 relative_path 字段）
CREATE TABLE files (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  original_name TEXT NOT NULL,
  file_path TEXT NOT NULL,
  relative_path TEXT,           -- 保存相对路径
  file_type TEXT NOT NULL,
  size INTEGER NOT NULL,
  status TEXT DEFAULT 'pending',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  processed_at DATETIME,
  is_deleted BOOLEAN DEFAULT 0
);
```

#### API 接口
- `GET /api/files` - 获取文件列表
- `POST /api/files/upload` - 上传文件（支持 relative_path）
- `GET /api/files/:id/download` - 下载文件
- `DELETE /api/files/:id` - 删除文件
- `POST /api/export/folder` - **导出文件夹（保持结构）** ⭐
- `GET /api/export/all` - 导出所有文件
- `GET /api/health` - 健康检查

#### 依赖包
```json
{
  "archiver": "^6.0.1",         // ZIP 打包 ⭐ 新增
  "better-sqlite3": "^9.6.0",   // SQLite 数据库
  "express": "^4.18.2",          // Web 框架
  "multer": "^1.4.5-lts.1",     // 文件上传
  "winston": "^3.11.0",          // 日志系统
  "cors": "^2.8.5"               // 跨域支持
}
```

## 🎯 核心功能演示

### 功能 1：文件夹上传（保持结构）

**步骤**：
```
1. 打开"文件上传"页面
2. 右上角切换到"文件夹"模式
   [📄 文件] ⬅️ [🔘] ➡️ [📁 文件夹]
3. 点击或拖拽整个文件夹
4. 点击"开始上传"
5. 等待完成 ✅
```

**效果**：
```
上传：MyProject/
      ├── docs/README.md
      └── src/main.js

结果：完整保留目录结构！
```

### 功能 2：批量导出（保持结构）⭐

**步骤**：
```
1. 打开"文件列表"页面
2. 勾选需要导出的文件
   [☑️] MyProject/docs/README.md
   [☑️] MyProject/src/main.js
3. 点击"导出为ZIP（保持目录结构）"
4. 自动下载 ZIP 文件
5. 解压验证 ✅
```

**效果**：
```
ZIP 内容：
└── MyProject/
    ├── docs/
    │   └── README-timestamp.md
    └── src/
        └── main-timestamp.js

✅ 目录结构完全一致！
```

### 功能 3：批量删除

**步骤**：
```
1. 打开"文件列表"页面

3. 界面显示：已选择 5 项
4. 点击"批量删除"
5. 确认操作 ✅
```
