# Phase 2 核心业务功能说明

## 📚 概述

FileProcessor v1.2.0 引入了强大的文档处理功能，包括 OCR 文字识别、PDF 拆分合并、文件预览等核心业务能力。本文档详细介绍这些新功能的使用方法。

---

## 🔍 功能 1：OCR 文字识别与脱敏

### 什么是 OCR？

OCR（Optical Character Recognition，光学字符识别）是将图像中的文字转换为可编辑文本的技术。

### 适用场景

- 📄 扫描件 PDF 文字提取
- 📸 照片中的文字识别
- 🔒 敏感信息自动脱敏
- 📊 批量文档处理

### 支持的文件格式

- ✅ PDF 文件
- ✅ JPG/JPEG 图片
- ✅ PNG 图片
- ✅ BMP 图片

### 使用步骤

#### 步骤 1：上传文件
```
1. 进入「文件上传」页面
2. 上传 PDF 或图片文件
3. 等待上传完成
```

#### 步骤 2：OCR 处理
```
1. 进入「PDF 工具」页面
2. 点击「OCR 识别与脱敏」标签
3. 在下拉框中选择要识别的文件
4. 打开「启用脱敏」开关（推荐）
5. 点击「开始识别」按钮
6. 等待处理完成（首次运行需要下载模型）
```

#### 步骤 3：查看结果
```
处理完成后会自动弹出结果窗口，显示：
- 每一页的原始文本
- 脱敏后的文本
- 页码信息
```

### 脱敏规则说明

| 信息类型 | 识别规则 | 脱敏效果 | 示例 |
|---------|---------|---------|------|
| 手机号 | 11位数字，1开头 | 保留前3后4 | 138****5678 |
| 身份证号 | 18位数字/字母 | 保留前6后4 | 110101********1234 |
| 邮箱地址 | xxx@xxx.xxx | 保留前2位 | ab***@example.com |
| 车牌号 | 省份+字母+数字 | 保留前2后2 | 京A***78 |

### 性能说明

| 文件类型 | 页数/张数 | 预计时间 |
|---------|----------|---------|
| PDF | 1 页 | 约 3-5 秒 |
| PDF | 5 页 | 约 20-30 秒 |
| PDF | 10 页 | 约 40-60 秒 |
| 图片 | 1 张 | 约 2-3 秒 |

**注意**：
- ⚠️ 首次运行需要下载 OCR 模型（约 10MB），需要网络连接
- ⚠️ 处理时间与图片质量、文字密度有关
- ⚠️ 建议在后台处理大文件

### 最佳实践

✅ **推荐做法**：
- 使用清晰的扫描件（DPI ≥ 300）
- 文档摆正，避免倾斜
- 文字清晰可辨
- 避免复杂背景

❌ **避免**：
- 模糊不清的图片
- 严重倾斜的文档
- 手写字体（识别率低）
- 艺术字体

## ✂️ 功能 2：PDF 拆分工具

### 适用场景

- 📑 提取 PDF 特定页面
- 📚 按章节拆分电子书
- 📋 分离大型文档
- 🎯 精确提取内容

### 拆分模式

#### 模式 1：按页码范围拆分

**使用场景**：需要精确控制拆分位置

**步骤**：
```
1. 进入「PDF 工具」→「PDF 拆分」
2. 选择要拆分的 PDF 文件
3. 点击后会显示 PDF 信息（总页数）
4. 保持「按页码范围」模式
5. 设置第一个范围，例如：1 - 10
6. 点击「添加范围」添加更多范围
7. 设置第二个范围，例如：11 - 20
8. 点击「开始拆分」
9. 等待处理完成
```

**示例**：
```
原文件：报告.pdf（共 30 页）

拆分设置：
- 范围 1：1 - 10
- 范围 2：11 - 20
- 范围 3：21 - 30

结果：
✅ split_1_pages_1-10.pdf（10 页）
✅ split_2_pages_11-20.pdf（10 页）
✅ split_3_pages_21-30.pdf（10 页）
```

#### 模式 2：按书签目录拆分

**使用场景**：PDF 包含章节书签，需要按章节拆分

**前提条件**：
- PDF 必须包含书签（目录）
- 书签结构清晰

**步骤**：
```
1. 选择包含书签的 PDF
2. 系统自动检测并显示书签数量
3. 切换到「按书签目录」模式
4. 点击「开始拆分」
5. 系统自动按一级书签拆分
```

**示例**：
```
原文件：教材.pdf

书签结构：
- 第一章 概述（第 1-10 页）
- 第二章 原理（第 11-25 页）
- 第三章 应用（第 26-40 页）

结果：
✅ 1_第一章概述.pdf（10 页）
✅ 2_第二章原理.pdf（15 页）
✅ 3_第三章应用.pdf（15 页）
```

### 注意事项

⚠️ **限制**：
- 页码范围不能超出总页数
- 起始页必须 ≤ 结束页
- 按书签拆分仅处理一级书签
- 无书签的 PDF 无法使用书签模式

💡 **提示**：
- 拆分后的文件自动保存到文件列表
- 可以在文件列表中预览、下载
- 原文件不会被删除

## 🔗 功能 3：PDF 合并工具

### 适用场景

- 📎 合并多个 PDF 文件
- 📚 整理文档集合
- 📄 制作完整报告
- 🗂️ 归档文件

### 使用步骤

```
1. 进入「PDF 工具」→「PDF 合并」
2. 在下拉框中选择要合并的文件
3. 至少选择 2 个 PDF 文件
4. 输入合并后的文件名（必须以 .pdf 结尾）
5. 点击「开始合并」
6. 等待处理完成
```

### 示例

**场景**：合并 3 个报告为一个完整文档

```
选择文件：
1. 报告-第一部分.pdf（10 页）
2. 报告-第二部分.pdf（15 页）
3. 报告-第三部分.pdf（8 页）

输出文件名：完整报告.pdf

结果：
✅ 完整报告.pdf（33 页）
   - 第 1-10 页：来自第一部分
   - 第 11-25 页：来自第二部分
   - 第 26-33 页：来自第三部分
```

### 合并特点

✅ **优势**：
- 保留原文件元数据
- 无损合并，不降低质量
- 按选择顺序合并
- 支持大文件（单文件 ≤ 5GB）

⚠️ **注意**：
- 文件按选择顺序合并，顺序很重要！
- 合并后的文件保存到文件列表
- 原文件保持不变

## 👁️ 功能 4：文件预览

### 适用场景

- 🔍 快速查看文件内容
- 📄 确认文件正确性
- 🖼️ 浏览图片
- 📝 查看文本

### 支持的文件格式

#### PDF 文件
- ✅ 内嵌预览
- ✅ 支持滚动翻页
- ✅ 无需下载

#### 图片文件
- ✅ JPG/JPEG
- ✅ PNG
- ✅ GIF（支持动画）
- ✅ BMP

#### 文本文件
- ✅ TXT（纯文本）
- ✅ JSON（格式化显示）
- ✅ LOG（日志文件）
- ✅ MD（Markdown）
- ✅ CSV（逗号分隔）

### 使用方法

```
1. 进入「文件列表」页面
2. 找到要预览的文件
3. 点击「预览」按钮（仅支持格式显示）
4. 在弹出窗口中查看内容
5. 可以直接从预览窗口下载文件
6. 点击「关闭」退出预览
```

### 预览示例

#### PDF 预览
```
✅ 显示完整 PDF 内容
✅ 支持滚动查看
✅ 保持原始格式
```

#### 图片预览
```
✅ 按比例缩放
✅ 自适应窗口大小
✅ 保持清晰度
```

#### 文本预览
```
✅ 保持原始格式
✅ 支持中文
✅ 显示行号（部分格式）
✅ 可滚动查看长文本
```

### 限制说明

❌ **不支持格式**：
- Word 文档（.doc、.docx）
- Excel 表格（.xls、.xlsx）
- PowerPoint（.ppt、.pptx）
- 视频文件
- 音频文件

💡 **建议**：
- 不支持格式请下载后查看
- Word 可转为 PDF 后预览
- 大文件（> 100MB）建议下载查看

## 🛠️ 技术架构

### 后端技术

```
Node.js + Express
├── PDF 处理：PyMuPDF（fitz）
├── OCR 识别：PaddleOCR
├── 子进程调用：child_process

```
python-scripts/

├── pdf_split.py        # PDF 拆分工具
├── pdf_merge.py        # PDF 合并工具

## 🎯 常见问题

### Q1：OCR 识别不准确怎么办？

**原因**：
- 图片质量差
- 文字模糊或倾斜
- 复杂排版
- 手写字体

**解决**：
- 使用高清扫描件（DPI ≥ 300）
- 确保文档摆正
- 简化排版
- 手写内容建议人工录入

---

### Q2：PDF 拆分后为什么没有书签？

**原因**：
- 拆分后的 PDF 是新文件
- 书签信息未复制

**说明**：
- 按页码拆分不会保留书签
- 按书签拆分会生成新的文件结构

---

### Q3：合并后的 PDF 文件很大怎么办？

**原因**：
- 原文件本身较大
- 包含高清图片

**建议**：
- 使用 PDF 压缩工具
- 降低图片质量
- 删除不必要的页面

---

### Q4：首次 OCR 很慢怎么办？

**原因**：
- 首次运行需要下载模型（约 10MB）
- 模型加载需要时间

**解决**：
- 确保网络连接
- 耐心等待下载完成
- 后续使用会快很多

---

### Q5：预览窗口显示不出来？

**检查**：
- 浏览器是否支持 iframe
- 文件是否已损坏
- 网络连接是否正常

**建议**：
- 使用 Chrome 或 Edge 浏览器
- 尝试重新上传文件
- 检查浏览器控制台错误
