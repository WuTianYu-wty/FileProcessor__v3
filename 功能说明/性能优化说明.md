## ⚡ 新增功能

### 1. 自定义姓名脱敏

#### 功能说明
除了自动识别常见姓名外，现在支持添加自定义姓名列表进行精确脱敏。

#### 使用方法

**前端界面**：
```
1. 进入「PDF 工具」→「OCR 识别与脱敏」
2. 在「自定义姓名列表」文本框中输入：
   张三
   李四
   王五
   （每行一个姓名）
3. 开启「姓名脱敏」开关
4. 点击「开始识别」
```

**效果**：
- 原文：张三的电话是 13812345678
- 脱敏：张*的电话是 138****5678

#### API 调用
```javascript
POST /api/ocr/process
{
  "fileId": 123,
  "enableNameDesensitize": true,
  "customNames": ["张三", "李四", "王五"]
}
```

#### 命令行脚本
```bash
# 创建姓名列表文件
echo "张三" > names.txt
echo "李四" >> names.txt

# 使用自定义姓名
python ocr_processor_enhanced.py input.pdf output.json --custom-names names.txt
```

### 2. 增强的脱敏规则

#### 新增脱敏类型

| 类型 | 识别规则 | 脱敏效果 | 示例 |
|-----|---------|---------|------|
| 手机号 | 1[3-9]xxxxxxxxx | 保留前3后4 | 138****5678 |
| 身份证 | 18位数字/字母 | 保留前6后4 | 110101********1234 |
| 银行卡 | 16-19位数字 | 保留前4后4 | 6222****1234 |
| 邮箱 | xxx@xxx.xxx | 保留前2位 | ab***@example.com |
| 车牌号 | 省份+字母+数字 | 保留前2后2 | 京A***78 |
| 地址 | 省市区路号等 | 保留前5后3 | 北京市朝阳区***号 |
| 姓名 | 2-3个汉字 | 保留姓氏 | 张** |

#### 自定义脱敏规则

```javascript
// 后端配置示例
const customPatterns = {
```

## 💡 优化建议

### 1. 针对 RTX 5070 的优化配置

```python
# ocr_processor_enhanced.py 配置
OCRProcessor(
    use_gpu=True,
    gpu_mem=1000,        # RTX 5070 有充足显存
    use_tensorrt=True,   # 启用 TensorRT 加速
    precision='fp16'     # 使用半精度提升速度
)
```

### 2. 批量处理优化

```javascript
// 批量处理多个文件
const files = [1, 2, 3, 4, 5]  // 文件 ID 列表

// 方案 1：并行处理（推荐，GPU 显存充足时）
await Promise.all(files.map(id => 
  axios.post('/api/ocr/process', { fileId: id, useGpu: true })
))

// 方案 2：串行处理（GPU 显存不足时）
for (const id of files) {
  await axios.post('/api/ocr/process', { fileId: id, useGpu: true })
}
```

### 3. 大文件处理策略

```
小文件（< 10 页）：
  ✅ 直接使用 GPU 处理
  ✅ 预计 < 10 秒

中等文件（10-50 页）：
  ✅ GPU 加速
  ✅ 预计 30 秒 - 2 分钟

大文件（> 50 页）：
  ✅ GPU 加速 + 批处理
  ✅ 后台异步处理
  ✅ 预计 > 2 分钟
```

## 🎯 最佳实践

✅ **推荐使用 GPU**：
- 批量处理多个文件
- 大型 PDF（> 10 页）

## 🐛 常见问题

### Q1：GPU 加速没有生效？

**检查步骤**：
```bash
# 1. 验证 GPU 可用
python -c "import paddle; print(paddle.is_compiled_with_cuda())"

# 2. 查看 GPU 使用
nvidia-smi

# 3. 检查日志
tail -f backend/logs/fileprocessor-*.log
```

### Q2：GPU 显存不足？

**解决方案**：
```python
# 减小 GPU 内存分配
gpu_mem=500  # 从 1000 降到 500

# 或降低图片分辨率
zoom = 1.5  # 从 2 降到 1.5
```

### Q3：姓名脱敏效果不理想？

**优化建议**：
1. 添加更多自定义姓名
2. 检查姓名是否为2-3个汉字
3. 查看识别结果中的原始文本
