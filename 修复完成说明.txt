   或手动清理 (备用方案):
   方式 A (推荐): 
   1. 打开文件资源管理器
   2. 导航到: D:\CODE\FileProcessor_v3\backend
   3. 删除 node_modules 文件夹
   4. 删除 package-lock.json 文件

   方式 B (命令行):
   cd backend
   Remove-Item -Recurse -Force node_modules
   Remove-Item -Force package-lock.json

步骤 3: 重新安装依赖 (如果手动清理)
   cd backend
   npm install

步骤 4: 启动项目
   .\start-dev.ps1

【常见问题快速解答】

Q: PowerShell 无法运行脚本？
A: 以管理员身份运行:
   Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

Q: 仍然看到乱码？
A: 使用 PowerShell 脚本或 GBK 编码版本:
   .\start-dev.ps1
   或
   .\start-dev-cn.bat

Q: 删除 node_modules 失败？
A: 1. 关闭所有命令行窗口
   2. 关闭 VS Code / Cursor
   3. 重启电脑
   4. 手动删除文件夹

Q: 端口被占用？
A: netstat -ano | findstr :3000
   taskkill /PID <PID> /F
